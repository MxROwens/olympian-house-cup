# Version 2 upgrade

No new SQL is required.

Before uploading these files to GitHub, open your CURRENT working `config.js` and copy its real:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY` (your publishable key)

Paste those two working values into this Version 2 `config.js`, replacing the placeholders.

Then replace the files in your existing GitHub repository with the Version 2 files and commit the changes. GitHub Pages will redeploy automatically.

Version 2 adds weekly standings, the May 13 2027 Race to Olympus countdown, grouped point categories, teacher analytics, mottos, and improved positive/deduction presentation.
